## Resumen

`ng-hub-ui-sortable` integra SortableJS en Angular para construir listas y layouts con drag and drop, reordenación, listas conectadas y sincronización con Signals o formularios reactivos.

## Instalación

```bash
npm install ng-hub-ui-sortable sortablejs
```

## Uso rápido

```typescript
import { SortableModule } from 'ng-hub-ui-sortable';
```

## Características

- API basada en directivas.
- Reordenación automática de arrays.
- Soporte para listas conectadas y clonación.
- Integración con Angular Signals y `FormArray`.
